# --- property-based testing --------------------------------------------------
# THIS IS THE ONE THAT EARNS ITS KEEP. The isolation matrix is the single most
# cited failure mode in the brief, and "we tested 25 cells" is an assertion
# while "we proved the matrix over the generated space" is a method. Four
# invariants in bible/05 §6b.2: monotonicity under role inclusion, no
# cross-evasion across generated actor/query pairs, decline-not-filter, and
# scope-is-total.
#
# Implementation notes that will save us an hour each (bible/05 §6b.2):
#   - subclass hypothesis.extra.django.TestCase so each example gets its own
#     transaction. NEVER TransactionTestCase: the Hypothesis docs warn it is
#     significantly slower in a loop.
#   - bound max_examples=50 and build small worlds with st.just / st.builds
#     rather than from_model() on the big tables.
#   - keep it in the verification suite, not the critical path.
hypothesis==6.168.3
